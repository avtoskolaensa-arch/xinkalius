# Xinkaliusi typography

- `3d-unicode.woff`: lossless web-font packaging of the owner's uploaded `3d_unicode.ttf` (3D Unicode Regular). Used for large decorative brand headings only.
- `bpg-nino-mtavruli-bold.woff`: BPG Nino Mtavruli Bold 2.001 (2008), BPG-InfoTech / Besarion Gugushvili. Used for menu items, navigation, prices, forms, buttons and administration.
  Source: https://www.fonts.ge/en/font/145/BPG-Nino-Mtavruli-Bold
  Author: https://bpgfonts.wordpress.com/
  Attribution: გამოყენებულია BPG-InfoTech ფონტები.

Both files retain their original glyphs and Unicode mapping. Georgian text uses
Mkhedruli code points. The font stack preserves system fallback for unsupported
symbols, including the lari sign. Fonts are self-hosted with `font-display: swap`.
